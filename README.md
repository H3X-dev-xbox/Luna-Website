## 🌙 About

This repository hosts the **official website** for **Luna Game Store** — a next-generation PC game launcher powered by FitGirl Repacks.

The site is built with **plain HTML, CSS, and JavaScript** — no frameworks, no build tools, no dependencies.

## 🚀 Live Site

Once GitHub Pages is enabled, the site will be live at:

**https://h3x-dev-xbox.github.io/luna-website/**

## 📁 Structure

```
public/        → Everything served to visitors
├── assets/    → CSS, JS, images, fonts
├── index.html → Landing page
└── ...
```
